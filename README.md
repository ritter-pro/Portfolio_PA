# PA–2004 / Полина Никулина

Финальное многостраничное портфолио: 140 статических страниц на русском и английском языках, восемь направлений, карусели, физические печатные мокапы, видео, увеличение изображений и 3D.

**Публикация:** [инструкция GitHub Pages](GITHUB-PAGES.md). Workflow `.github/workflows/pages.yml` публикует `dist/` после push в `main`; `prepare-pages.py` подставляет адрес Pages в метаданные. Сайт не требует Node.js, серверного приложения или API-ключей.

Локальный просмотр: `python3 -m http.server 8000 --directory dist`, затем `http://localhost:8000/`.

## Исходники

- `dist/` — готовые страницы и ресурсы, RU в корне, EN в `en/`.
- `atelier-data.json`, `packaging-data.json` — данные кейсов.
- `templates-final/` — базовые шаблоны главной, соцсетей и кодинга.
- `finalize-content.py` — актуальный генератор; `render-final.py`, `polish-site.py` — его этапы.
- `optimize-site.py` — подготовка печатных текстур, адаптивных изображений и CSS.
- `check-site.py` — проверка локальных ссылок, ресурсов и якорей.

Для генерации: `python3 -m pip install -r requirements.txt`, затем `python3 finalize-content.py`, `python3 optimize-site.py`, `python3 check-site.py`. При генерации правьте также данные/шаблоны, чтобы сохранить изменения. Старые `build*.py`, `localize.py`, `redesign.py`, `prepare-final-assets.py`, `correct-content.py` — исторические импортёры; не запускайте их поверх финальной версии.

## Оптимизация

Локальные Manrope и IBM Plex Mono с лицензиями в `assets/fonts`. Адаптивные WebP 480/960/1440 px выбираются по экрану; полноразмерные работы сохранены для увеличения. Галереи подгружают текущий и следующий слайды. Убрана блокирующая декоративная заставка. CSS объединён с сохранением каскада. Библиотеки 3D запускаются после появления основного интерфейса; модель загружается отдельно.

Печатные текстуры заранее подготовлены в `assets/print-ready`, без canvas-обработки на устройстве посетителя. Геометрия, пропорции и весь видимый дизайн сохранены. Оригинальные PNG и происхождение — `assets/print-originals` и `assets/print-manifest.json`. У исходных PNG уже есть прозрачные скругления; фон маленьких отсутствующих углов продолжен ближайшим непрозрачным цветом. Скрытое изображение под прозрачностью не восстанавливалось.

Все десять инструкций сверены с исходными PDF; первым идёт настенный светильник. Лента и ИК-выключатель имеют правильные названия и обложки. Удалено дублирующее сравнение ретуши. В кодинге первыми идут PIM, бот и портфолио.

YouTube требует интернета и запускается по нажатию. 3D требует WebGL; при его отсутствии есть резервный вид. Облачный QA-браузер не поддерживает WebGL, поэтому финальный 3D-рендер в нём не проверяется.
