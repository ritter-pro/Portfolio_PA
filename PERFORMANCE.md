# Проверка оптимизации PA–2004

- В браузере на первом экране главной нет запросов к семи изображениям нижней карусели. Они получают источники только при приближении галереи к экрану.
- В галерее инструкций при открытии загружены текущий и следующий слайды; восемь остальных изображений остаются отложенными. Используются адаптивные WebP.
- Для печатных работ исходные PNG занимают 29 195 254 байта; подготовленные текстуры — 5 344 924 байта (примерно на 82% меньше). Это сравнение объёма набора файлов, а не обещание ускорения всего сайта на 82%. На устройстве посетителя больше нет вычисления масок и кодирования canvas.
- Шрифты загружаются локально, без запроса к Google Fonts; декоративная блокирующая заставка удалена. CSS объединён, 3D-библиотеки запускаются после основного интерфейса.
- RU/EN: 140 страниц, локальные ссылки и якоря без ошибок; 1 644 ссылки адаптивных изображений и ссылки печатных текстур проверены.
- Мобильные iframe шириной 375 px проверены визуально. Фактическая область документа с полосой прокрутки — 360 px: scrollWidth равен clientWidth, горизонтального переполнения нет.
- GitHub Pages: подготовка метаданных проверена для адреса с `/Portfolio_PA/`, включая английские страницы. Сам workflow на GitHub ещё не запускался.

Проверка выполнена в локальном предпросмотре. Скорость реального интернета зависит от сети, устройства и хостинга; реальные полевые Core Web Vitals не измерялись. Облачный браузер не поддерживает WebGL: проверен резервный вид, но не финальный 3D-рендер.
